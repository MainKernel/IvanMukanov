# Клієнт API

Лабораторна № 1, крок 5. Тут лежить `client.ts` — типізований клієнт,
створений через `openapi-fetch` на основі типів із `@eventhub/contracts`.

## Правило, яке діє весь семестр

**Типи запитів і відповідей ніхто не пише руками.**

Якщо у цій папці з'явився рукописний `EventDto` (інтерфейс чи тип) — ви створили
другу версію правди. Специфікація каже одне, інтерфейс — інше, і поки
вони збігаються, все добре. Розійдуться вони мовчки: хтось змінить YAML,
забуде інтерфейс, компілятор нічого не помітить, бо для нього це два
незалежні тексти.

Згенерований тип таку розбіжність робить неможливою за побудовою.

Критерій приймання № 6 перевіряє це буквально — командою `grep` з таблиці
критеріїв у `docs/labs/lab-01-metodychka.md` (розділ 12). Її вивід по
`apps/web/src` має бути порожнім. Саму команду сюди не скопійовано
навмисно: інакше вона знаходила б власний текст у цьому файлі.
